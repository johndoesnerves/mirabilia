# ASTRAへの依頼：MIRABILIA 残り52作品の動画台本（2026-11-17）

## ブランドと動画の前提
- MIRABILIA（ミラビリア）は「名画を着る、知ればもっと着たくなる。」を核コピーとする、名画プリントのアパレルブランド（Tシャツ／ロンT／トート）。
- SNS動画は「名画解説」型の縦型リール（1080×1920）。ナレーション型（型B）が現行標準。
- 動画の流れ：絵を大きく見せる → 核の「へぇ」 → 視聴者への問い → 作者名・作品名を最後に「答え」として出す → ブランドの一言。**作品名は最後まで出さない**。販売・商品への言及は一番最後だけ（ナレーションには入れない）。
- 筆頭10作品は制作済み／制作中。本依頼は残り52作品分（内訳と優先順は `works-list.md`）。

## 台本の作り方 v2（必須・全作品共通）
1. **「へぇ」は1本に1つ**。核の驚きを1つ決め、他の要素は全部その補助に回す。余ったトリビアはキャプションへ逃がす
2. **絵で見えるものだけを話す**。ナレーションの各文は「画面のどこを見ればいいか」が分かること。前提知識が要る話（シリーズ・時代背景・画家の生涯）は本筋にしない
3. **順番は「見える → 疑問 → 答え」**。具体物を見せ、短い疑問を置き、答えで回収する
4. **1文1情報・短文でつなぐ**。抽象語でまとめない。解釈は最後に1文だけ置く
5. **冒頭3秒は絵の中の具体物**から入る（数字・年号・概念から入らない）
6. **初見テスト**：作品を知らない人が1回聞いて、核の「へぇ」を言い返せるか。言い返せなければ作り直す

## 台本の形式（1作品ごと）
- **動画タイトル**：短く、意外性＋疑問で止める形（例：「眠ると怪物が生まれる！？」）。「！」は使いすぎない。作品名はタイトルに入れてよい（伏せるのは動画本編の中だけ）
- **ナレーション**：番号付きの短文で6〜9文。最後の2文は固定：
  - 「（作者フルネーム）、《作品名》。」
  - 「名画を着る、知ればもっと着たくなる。ミラビリア。」
  - その直前に、視聴者への問いを1文置く
- **キャプション**：1〜2行。本筋に入らなかったトリビアをここへ。ハッシュタグは付けない
- **カメラワークメモ**：冒頭の寄り／核の細部／答えでの引き、を3〜5行で
- **事実メモ**：使った事実の根拠（所蔵館の解説等）と、断定を避けた箇所・要確認点を明記する。**不確かな話は「〜と言われています」の形にするか、使わない**
