# for-gpt/ — GPT への指示置き場

スシ（司令塔）から **GPT（ASTRA／ChatGPT）** への指示はここに入る。Claude への指示は `for-claude/` にあるので混ぜない。

## 置き方
- トピックごとにフォルダを作る：`for-gpt/<topic>/`
- フォルダの中身：
  - `brief.md` — 指示書（作ってほしいもの・条件・分量）
  - 素材ファイル（参照資料など）
  - `handoff.md` — GPT が成果物と一緒に書くメモ（GPT が作成）
  - `request.md` — GPT からスシへの依頼・確認（GPT が作成）
- 成果物（台本など）は同じフォルダ内か、指定された場所へ。
