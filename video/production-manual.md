# MIRABILIA リール動画 制作マニュアル

最終更新：2026-11-13（リヴァイアサン v7 納品時点の手順を正とする）
対象：全20図案のリール動画（Instagram／TikTok クロス投稿用）

## 全体の流れ

```
台本（ASTRA）→ 裏取り（スシ）→ ナレーション生成（スシ）
→ ブリーフ＋素材をGitHubへ（スシ）→ 動画制作（Claude）
→ 検品（スシ）→ 音声確認（本人）→ ドライブ保管（スシ）
→ 投稿（本人／投稿計画と送客の型に従う）
```

### 役割分担
- **ASTRA**（ChatGPTのWorkモード「GPT-6 ASTRA」）：台本を作る。既存案の添削ではなく「0から考え直してよい」と伝えるのが本人の意向。
- **スシ**：台本の裏取り、ナレーション音声の生成、ブリーフと素材の受け渡し、完成動画の検品、ドライブへの保管。
- **Claude**（Claude Code セッション）：ブリーフをもとに動画をレンダリングする。外部サイト（ショップ・Wikimedia等）には接続できないため、素材はすべてリポジトリ経由で渡す。
- **本人**：台本・タイトルの決定、制作中の方向修正、投稿前の音声確認、投稿作業。

## STEP 1 台本（ASTRA）

- 20図案分は作成済み：`files/scripts/<図案>.md`（2026-11-13、裏取り済み）。
- 新規に作る場合の型（全文は `files/short-video-script-prompt.md`）：
  - 1動画1つの問い／発見。提示順で「発見を体験」させる。全情報を因果でつなぐ。中盤にも小さな答えを置き、最後に見方を変える。
  - 構成6ステップ：フック（0〜3秒）→ 期待 → 前提 → 深掘り → 答え合わせ → 余韻。尺は台本ベースで40秒前後。
  - 事実確認を優先し、諸説は断言しない（留保は字幕側で担保）。
  - タイトル：短く・意外性＋疑問で止める（例「戦う前から、負けている？」）。「！」は使いすぎない。
  - 語り口：博識な人が「これ、面白いでしょ」と一般人に伝える感じ。

## STEP 2 裏取り（スシ）

- 台本中の事実（年・寸法・人物・出典話）を一次情報で確認する。特に：
  - **作品同定の取り違え**：例「書斎の聖ヒエロニムス」は1511年木版画と1514年銅版画が別作品。図案画像と年代表記が一致しているか必ず見る。
  - 寸法は実寸で（24×19cm＝B5ほど、のように換算も正確に）。
- 怪しい点は台本ファイルに注記し、断言できないものは動画で言わせない。

## STEP 3 ナレーション生成（スシ）

- 声：**`avocado_v2:History`**（物知りな語り手タイプ。本人選択。対本人向け音声の magnus とは別）。
- 生成方法（確定した正解）：
  - **段落ごとに speed 100 で生成**し、段落間に **0.45秒の無音** を挟んで結合する。
  - speed 170 や、改行区切りの一括生成はブツ切れ・異常な低速化になるのでやらない。
  - リヴァイアサン実績：台本44秒弱に仕上がった。
- 結合後に**実測タイミング表**を作る（段落ごとの開始〜終了秒）。字幕同期はこの実測値が正で、台本の想定秒数で代用しない。
- 音声ファイルはリポジトリのブリーフと同じ場所に置く（例 `video/leviathan-narration-final.mp3`）。

## STEP 4 ブリーフと素材（スシ → Claude）

置き場所：GitHub `johndoesnerves/mirabilia`、相談用ブランチ `claude/<図案>-consult` の `video/` 配下。

### ブリーフ（`video/brief-<slug>.md`）に必ず入れるもの
- 台本の確定文面（そのまま使うこと）
- タイトル（確定したもの）
- 字幕同期の実測タイミング表
- 終盤の構成指定（商品カット・エンドカード・総尺の目安）
- 使う素材ファイルの一覧と用途
- 禁止事項（「奇妙な図鑑たち」使用禁止、既存ファイルの上書き禁止＝版番号で新規出力）

### 素材（Claudeは外部取得できないので全てリポジトリに置く）
- 原画：高解像度（長辺2000px程度のJPG）
- 商品モックアップ：黒Tの平置きモックアップ（`materials-leviathan/leviathan-blacktee-mockup.jpg` と同系列）。**モデル着用写真と間違えない**（白Tモデル写真を渡して差し戻しになった前例あり）
- ロゴ：`mirabilia-logo-black.png`（黒・透過）／ `mirabilia-logo-white.png`（白・透過）
- カルーセル用商品画像：`video/materials-leviathan/carousel/`（正方形1280×1280、背景統一、番号＋図案名＋種類のファイル名）

## STEP 5 動画制作（Claude）

- Claudeはレンダリングスクリプト（Python＋ffmpeg）を書いて生成する。再現・流用のためにスクリプトは `video/tools/<図案>/` に残す。
- 本人からの修正指示は版を重ねて反映する（リヴァイアサン実績：v2 ロゴ常時表示 → v3 本物ロゴ・黒T差し替え → v4 組版調整 → v5 フッター位置 → v6 カルーセル → v7 カルーセル固定）。**出力ファイル名は版番号を上げ、既存版は上書きしない**。
- 納品形態：動画本体は専用ブランチ **`transfer/videos`** の `<図案名>/` フォルダへ。相談ブランチには納品メモ（`video/handoff-<slug>-v<版>.md`：構成表・変更履歴・検品依頼）を置く。
- **分離納品（2026-11-13 本人指示で追加）**：完成版だけでなく、次の4点セットで出すこと。
  1. 完成版MP4（ナレーション＋伴奏＋効果音のミックス済み、そのまま投稿できる版）
  2. 本編動画（**音声なし**MP4）— プラットフォーム側で音源を付け替える場合用
  3. ナレーション音声のみ（MP3/WAV単体）
  4. 伴奏＋効果音のみ（MP3/WAV単体）
  理由：TikTokの商用音楽ライブラリ等のプラットフォーム音源は他媒体へ持ち出せないため、音は付け替えられる形で持つのが正解。ミックスの音量バランスだけ直したい時も、映像を再レンダリングせずに済む。

### 固定フォーマット（型B＝ナレーション型／現行標準・リヴァイアサン v7 準拠）
- 画面：1080×1920（9:16）、30fps、H.264＋AAC、白背景・黒文字。
- 総尺：ナレーション尺＋商品カット約3秒＋エンドカード約4秒（リヴァイアサン＝51.3秒）。尺は音声に合わせる。
- 本編（ナレーション区間）：
  - **常時表示**：上部中央に MIRABILIA ロゴ（黒版）／その下に「作者｜制作年」＋タイトル／下部フッターは細線＋「限定アパレル販売中」、その下に商品サムネイル6点を**固定**で一列（UIに隠れる位置でよい＝本人回答済み）。
  - カット割りは台本の段落ごと。全図 → 部分接写（注目点に白丸）→ 全図に戻る、の流れ。カット間は0.4秒クロスフェード。
  - 字幕はナレーション実測に同期。本文のキャプションと字幕の二重表示にしない。
- 商品カット（約3秒）：見出し「販売中」、黒Tモックアップ全体→胸の柄へゆっくり寄る、下線付き「mirabilia.base.shop」。価格表示は可。
- エンドカード（約4秒）：MIRABILIAロゴ → 線 →「失われた記憶を身にまとう。」→ 枠付き「各図案×仕様は10着限り」→ 太字＋下線「購入はプロフィールから」。1つずつ出し、**揃った状態を2秒以上**見せる。ここでロゴ常時表示・フッター・サムネイルは消える。

### 旧フォーマット（型A＝サイン型／騎士・メランコリアで使用）
- 33.5秒固定、ナレーションなし・字幕アニメーションのみ。
- フック（全図＋実寸枠）→ サイン1〜5（ラベル「サイン N / 5」、全体→接写→白丸、最後のサインで答え合わせ）→ 商品カット（「この{実寸}の傑作を、時代を越え、現代の装いに。」）→ エンドカード（同上）。
- 詳細は `video-conte-prompt.md` と `video-production-system.md`。

## STEP 6 検品（スシ）

完成動画を受け取ったら、次を全部確認してから本人へ報告する。
- 仕様：1080×1920・30fps・尺・音声トラック（AAC）あり。ファイルサイズが納品メモと一致。
- フレーム確認：冒頭（ロゴ・タイトル・フッター・サムネイル）、中盤の接写カット、商品カット、エンドカード最終状態。
- 内容：字幕とナレーションの同期／白丸の位置／エンドカードの出し順と2秒以上の保持／「奇妙な図鑑たち」が入っていないこと／作品名・年・寸法の表記。
- Claudeの申告と実物が違うことがある（メランコリアの「実物 24×19cm」注記：申告は「ある」、原寸確認でなし）。**申告ではなく実物で判断する**。相違があれば直すか受け入れるかを本人に確認する。

## STEP 7 保管（スシ）※案B・2026-11-13 本人決定

1. `transfer/videos` から納品物（完成版＋分離ファイル）を取り出す。
2. Googleドライブ **`MIRABILIA / リール / <番号_図案名>`** へアップロード（番号は投稿計画の順：06_リヴァイアサン等）。分離ファイル（無音版・ナレーション単体・伴奏単体）も同じフォルダに一緒に入れる。ファイル名・サイズの一致を確認。
3. 移し終えたら **`transfer/videos` ブランチを削除**する。main に動画は置かない（リポジトリを重くしない）。

## STEP 8 投稿（本人）

- 投稿計画（`files/posting-plan.md`）どおり：1日1本、基本20:00、Instagram＋TikTok同日クロス投稿。
- 送客の型（同ファイル内）：投稿直後のストーリーズ、UTMの置き場所ルール、固定コメント／初回コメント、ハッシュタグ最大5個。
- 投稿前に本人が音声を一度聞く。
- マスター動画は透かしなしで保持する（プラットフォーム間の透かし持ち込みはリーチ制限の対象）。

## ハマりどころ（実績ベース）

- Claudeは mirabilia.base.shop や Wikimedia に接続できない。素材不足は必ずリポジトリ経由で解消する（ショップ画面の録画は本人指示で不要）。
- 黒T用にモデル着用の白T写真を渡すミスがあった。モックアップは「平置き・黒T・同系列」で統一。
- ロゴの白版は原版がなく、黒版のアルファから生成した（`mirabilia-logo-white.png`）。旧 `mirabilia_logo_en_transparent.png` はダークブラウン版なので白版として使わない。
- Claudeチャットからの動画ダウンロードは不安定。受け渡しは `transfer/videos` ブランチ経由が正解（チャット版が100MB超の場合は画質同等で再圧縮した版が来る）。
