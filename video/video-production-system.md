# MIRABILIA リール動画 量産システム（2026-11-12 構築）

1作目「騎士と死と悪魔（ピンチ版）」で本人が高評価した型を、全図案に再現するための量産手順。
ルールの詳細は `video-conte-prompt.md`（標準プロンプト＋プロの原則＋語り口＋タイトル制作ルール）に従う。このファイルは工程と管理表。

## 一番大事なこと
- **一つのストーリーにする**。フックで立てた問いを、サイン5つが順に説明し、最後のサインで答え合わせになる一本筋。豆知識の羅列は禁止（ピンチ版：フック「実はかなりピンチです」→理由1〜4→「なのに振り向かない」が答え）。
- 語り口は「博識な人が、一般人に『これ、面白いでしょ』と伝える」温度。

## 工程（1図案 = 1本）
**分担の原則（2026-11-12 本人指示で変更）：調査・解釈・テキスト案は Claude が作る。** スシはルールと素材を渡し、裏取り検品をして、本人の判断まで運ぶ。本人が選ぶ・決める。

1. **企画一式の作成**（担当：Claude、claude.ai）
- 渡すもの：原画画像＋黒T商品画像、ブランドのルール一式（下記ブリーフ）、固定フォーマット。
- Claudeが作るもの：
  a. **深掘り調査**：あまり知られていない具体事実8〜10個（出典つき、事実と説を区別）。浅い有名事実だけで作らない。狙う事実：作者本人の記録・メモ／決着していない議論／隠れた個人的事情／意外な意味や役割。
  b. **解釈＝ストーリー設計**：事実から「一つのストーリー」の芯を1つ提案。サイン5つは全部その芯の説明になり、最後のサインでフックを回収する構成。
  c. **タイトル案**：ルール（10〜18文字で言い切る／意外な事実＋疑問形（！？・？）で止める／留保はタイトルに入れない（字幕で担保）／作品固有の事実のみ／専門用語なし）で6案＋おすすめ1案。基準例：「この数字で鬱を防ぐ！？」、従来確定例：「この騎士、実はかなりピンチです」。
  d. **コンテ案**：固定フォーマットに沿った全カットの見出し・字幕・映像案と、事実確認メモ。
- この段階では動画はまだ作らない。
2. **批評・修正ループ**（担当：チャッピー → Claude、2026-11-12 本人指示で追加）
- Claudeの企画案が出たら、チャッピー（ChatGPT文案スレッド）に渡して **批評的に判断** させる（ルール適合・ストーリーの一本筋・事実の扱い・語り口を厳しく見る）。
- チャッピーには批評だけでなく **修正した案（企画一式の修正版）** まで作らせる。
- その修正案をClaudeに返し、Claudeがさらに修正した **最終案** を受け取る。
- 本人に出すのは、このループを通した最終案（＋スシの裏取り結果）。
3. **裏取り・検品**（担当：スシ）
- 事実リストの要点を出典で裏取りする（特に年・寸法・図像の同定。1511木版画と1514銅版画の取り違え事故を繰り返さない）。使われた画像が本当にその作品か確認する。
- タイトルとコンテを検品チェックリスト（video-conte-prompt.md）にかける。外れたら理由を明示してClaudeに作り直させる。
4. **本人の判断**（担当：本人）
- タイトルを選ぶ。ストーリーの芯とコンテを通す。
5. **動画制作**（担当：Claude）
- 確定コンテでMP4（1080×1920）を作らせる。別ファイル名で出力させ、既存版は上書きしない。有料加入なし・投稿なし。
6. **検品**（担当：スシ）
- 全カット再生確認：コンテとの一致／サインの丸印の位置／エンドカードの出し順と「揃った状態2秒以上」／廃止表現「奇妙な図鑑たち」が入っていないか。
- Claudeから事実関係の指摘が出たら、裏取りして本人に判断を仰ぐ（ツルハシの件：V&A公式解説が pickaxe と明記 → 本人判断でそのまま確定、という処理が前例）。
7. **受け取り**（担当：本人）
- ブラウザからはダウンロードできないため、完成ファイルはClaudeチャット内から本人が取得する。投稿前に音声を本人が一度聞く。

## Claudeへのブリーフ（毎回渡すルール要約）
- ブランド：MIRABILIA。コンセプト「失われた記憶を身にまとう。」。「奇妙な図鑑たち」は使用禁止。
- 語り口：博識な人が「これ、面白いでしょ」と一般の人に伝える感じ。事実の羅列・図録調・安っぽい煽りは禁止。
- 一つのストーリー：フックの問いをサイン5つが順に説明し、最後に答え合わせ。解釈は「〜という読み方がある」で止める。
- Instagramのプロ原則：最初の3秒で一番おもしろい事実を先出し。タイトルは1秒目から画面に。言葉と最初のカットの映像をそろえる。釣り禁止。
- フォーマット：33.5秒固定（下記）。

## 固定フォーマット（33.5秒）
- 0:00 フック（約4秒）：全図→引いて実寸の枠と寸法線。ラベル「作者名｜制作年」、見出し＝タイトル、字幕「B5ほどの1枚に隠れた、〜（ストーリーの芯）」
- 0:04〜 サイン1〜5（各約4.5〜5秒）：ラベル「サイン N / 5」。リズムは 全体→接写→白丸印。見出し＝見える事実、字幕＝その意味
- 0:27 商品（約2.5秒）：「この{実寸}の傑作を、時代を越え、現代の装いに。」黒Tモックアップにゆっくり寄る
- 0:29.5〜0:33.5 エンドカード：MIRABILIA →「失われた記憶を身にまとう。」→ 枠付き「各図案×仕様は10着限り」→ 太字＋下線「購入はプロフィールから」。1つずつ出し、揃った状態を2秒以上
- 共通：9:16（1080×1920）、ナレーションなし・字幕アニメーションのみ、白背景・黒文字、軽い伴奏＋軽い効果音、重いホラー調にしない
