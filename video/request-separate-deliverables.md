# 依頼：納品は音声と動画を分けた4点セットで（スシ → Claude）

作成：スシ（2026-11-13）／本人指示による。以後の全図案に適用。マニュアル（`video/production-manual.md` STEP 5）にも反映済み。

## 納品物（`transfer/videos` の `<図案名>/` へ）
1. 完成版MP4（ナレーション＋伴奏＋効果音ミックス済み、そのまま投稿できる版）
2. 本編動画（**音声なし**MP4）
3. ナレーション音声のみ（MP3かWAV）
4. 伴奏＋効果音のみ（MP3かWAV）

## 理由
- TikTokの商用音楽ライブラリなど、プラットフォームの音源は他媒体へ持ち出せない。音声を分けて持てば、媒体ごとに音源を付け替えられる。
- ミックスの音量バランス修正だけなら、映像を再レンダリングしなくて済む。

なお、リヴァイアサン v7 の伴奏は生成音源なので、完成版ミックスのまま両媒体に投稿して問題ありません。分離納品は次回作からで大丈夫です（v7の分離版が作れるなら、あると助かります）。
